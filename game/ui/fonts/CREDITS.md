# Fonts

Both families are used under the SIL Open Font License 1.1. The full licence
text for each ships alongside the font files in `ui/fonts/`.

| File | Family | Source | Licence |
|---|---|---|---|
| `ui/fonts/Oswald-Variable.ttf` | Oswald | [Google Fonts](https://fonts.google.com/specimen/Oswald) | OFL 1.1 — `ui/fonts/OFL-Oswald.txt` |
| `ui/fonts/BarlowCondensed-Regular.ttf` | Barlow Condensed | [Google Fonts](https://fonts.google.com/specimen/Barlow+Condensed) | OFL 1.1 — `ui/fonts/OFL-BarlowCondensed.txt` |
| `ui/fonts/BarlowCondensed-Medium.ttf` | Barlow Condensed | as above | as above |
| `ui/fonts/BarlowCondensed-SemiBold.ttf` | Barlow Condensed | as above | as above |

Oswald is the display face (title, item names, pause menu headings). Barlow
Condensed carries everything else. The OFL permits bundling and redistribution
inside a game, including commercially; it only forbids selling the fonts on
their own and requires the licence travel with them, which it does here.
